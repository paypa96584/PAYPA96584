# PAYPA96584 — Royal Fine Jewelry

**Crafted for Timeless Elegance.**

Responsive, English-language luxury jewelry concept storefront. Colors: Burgundy `#521D30`, Champagne `#E4C79A`, Ivory `#FFF8EE`.

## Pages
Home, Collections, Our Story, Gallery, Contact, FAQ, Privacy, Terms.

## Run locally
Open `index.html` in a modern browser. Internet is required for external Unsplash photographs and Google Fonts.

## Publish to GitHub Pages
Upload all files and folders to the root of a public GitHub repository. In Settings → Pages, select Deploy from a branch, main, /(root).

## Important
This is a **demo only**. Product images and prices are illustrative. The bag stores item names in localStorage but has no checkout; the contact form does not send messages. No payments, orders, shipping, or backend are connected. Replace example images and legal pages before commercial launch.
